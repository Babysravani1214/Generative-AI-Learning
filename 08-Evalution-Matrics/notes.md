# Machine Learning Model Evaluation

## Train-Test Split
- Learned how to divide the dataset into training and testing data.
- Understood the importance of choosing a suitable train-test ratio.
- Learned how test data is used to evaluate model performance.

## Evaluation Metrics
- Learned about Accuracy, Precision, Recall, and F1 Score.
- Understood how the Confusion Matrix helps evaluate classification results.
- Learned how different metrics measure model performance.

## Cross Validation
- Learned the concept of Cross Validation.
- Understood how K-Fold validation is used to evaluate a model.
- Learned how cross validation helps provide reliable performance results.

## Overfitting and Underfitting
- Learned how overfitting occurs when a model learns the training data too closely.
- Understood how underfitting occurs when a model is too simple to learn the patterns.
- Learned how model performance can be compared using training and testing results.

## Key Takeaway

I learned how to evaluate a Machine Learning model using train-test split, evaluation metrics, and cross validation. I also understood overfitting and underfitting and how they affect model performance.
